# Frontend — Malaysia Health Equity Tracker

This is the React + TypeScript + Vite + Tailwind CSS frontend for the
Malaysia Health Equity Tracker. It's a static single-page app: it reads
pre-built JSON data from `public/data/` (generated by the Python pipeline in
`../scripts/`) and renders 9 dashboard pages — there is no backend server.

For the full project overview, how to run/build/deploy, and data
documentation, see the repository root:

- [`../README.md`](../README.md) — project overview, setup, build & deploy instructions
- [`../docs/METHODOLOGY.md`](../docs/METHODOLOGY.md) — pipeline & analysis methodology
- [`../docs/DATA_DICTIONARY.md`](../docs/DATA_DICTIONARY.md) — field-by-field reference for every JSON file in `public/data/`
- [`../docs/DATA_SOURCES.md`](../docs/DATA_SOURCES.md) — full source catalogue

## Quick start

```bash
npm install
npm run dev       # local dev server with hot reload
npm run build     # production build -> dist/
npm run preview   # serve the production build locally
```

This project was scaffolded with `npm create vite@latest -- --template react-ts` and then extended with Tailwind CSS v4, Recharts, Leaflet/react-leaflet, react-router-dom, and simple-statistics — see `package.json` for the full dependency list.
